# TFT_eSPI examples

This directory holds examples of using the TFT_eSPI library.

When using TFT_eSPI you need to configure the `User_Setup.h` file for the display controller you are using. I have included the required `User_Setup.h` file with the example code. You need to copy the `User_Setup.h` file from the example into your library/TFT_eSPI directory.
