# ILI9341-CYD

This demonstrates how to use an ILI9341 SPI display with the Arduino GFX library.

To use this you need to install the _Adafruit ILI9341 by Adafruit_ library from the Library Manager.

This sketch was written for the cheap yellow display (CYD) boards, and it has the GPIO pins set to those used by the CYD. You can use the code for any ILI9341 display but you will need to edit the GPIO pin numbers at the top of the code to match the pins you have used.
